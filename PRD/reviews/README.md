# Артефакты независимого ревью

Для каждой нетривиальной задачи сохраняйте заключение `YYYY-MM-DD-<тема>-prd.md` до реализации и `YYYY-MM-DD-<тема>-diff.md` после неё. Допустима ссылка на содержательное ревью PR, если она доступна будущему исполнителю.

В заключении укажите рецензента (другой агент или человек), базу и проверенный SHA/diff, перечень прочитанных файлов, важность и текст замечаний, результат повторной проверки. Исполнитель отдельно фиксирует принятое исправление или обоснованный отказ. Авторская самопроверка, запуск тестов и приглашение рецензента без ответа не являются независимым ревью.
